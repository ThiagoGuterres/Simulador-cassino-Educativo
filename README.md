# 🎰 Simulador Didático: A Matemática por Trás das Bets

Projeto interativo desenvolvido para demonstrar visualmente e estatisticamente por que as casas de apostas e cassinos online são desenhados para garantir o lucro do operador e a falência do apostador no longo prazo.

📱 **Acesse a simulação pelo celular/navegador:** [INSIRA_SEU_LINK_DO_GITHUB_PAGES_AQUI]

---

## 🎯 Objetivos do Projeto
- **Demonstrar a "House Edge" (Vantagem da Casa):** Mostrar que, no longo prazo, a expectativa matemática é sempre negativa para o jogador.
- **Explicar o RTP Dinâmico:** Simular como sistemas virtuais alteram a taxa de retorno para dar "falsas vitórias" no início e reter o apostador.
- **Evidenciar Gatilhos Comportamentais:** Ilustrar o efeito *Near-Miss* ("Quase Vitória"), usado para estimular a produção de dopamina e manter o usuário jogando.

---

## 🛠️ Tecnologias Utilizadas
- **HTML5 / CSS3:** Interface responsiva otimizada para smartphones (WhatsApp WebView).
- **JavaScript (ES6):** Algoritmo de simulação e controle de probabilidades.
- **Chart.js:** Gráfico em tempo real comparando a falência do saldo do jogador com o crescimento do lucro da casa.
- **Tailwind CSS:** Estilização visual no formato de caça-níquel clássico.

---

## 🔬 Como Funciona a Simulação?
1. **Modo Jogo Limpo:** A casa opera com probabilidades estáticas ajustadas para uma margem matemática constante.
2. **Modo Script Agressivo:** O jogo simula um algoritmo de retenção — o jogador ganha nas primeiras 10 rodadas (RTP alto), mas a taxa despenca conforme ele continua jogando, drenando a banca.
